# تقرير المراجعة الأمنية — المرحلة 7

تاريخ المراجعة: 6 أكتوبر 2026. النطاق: مسارات Laravel، حسابات الأستاذ والطلاب، المناهج والمرفقات، HLS ومفاتيحه، عامل الفيديو، ملفات الإعداد والتبعيات.

## الملخص التنفيذي

عولجت في هذه المرحلة ثلاث فجوات واضحة: غياب رؤوس أمان موحدة، تفعيل `serve` على قرص `local` الذي يشير إلى مسار الملفات الخاصة، وعدم وجود حد طلبات مستقل لملفات HLS وصفحات الملازم. أضيفت رؤوس CSP وغيرها، وأوقف تقديم القرص المحلي، وأضيف حد 240 طلباً للدقيقة لكل طالب وعنوان IP لمسارات البث والعارض. بقيت حماية المحتوى حماية وصول وردع؛ لا تحول AES-128 أو التطبيق المكتبي دون تسجيل الشاشة بكاميرا خارجية.

## نقاط يجب إتمامها عند النشر

1. `APP_DEBUG=false` و`APP_ENV=production` و`APP_URL=https://...` و`SESSION_SECURE_COOKIE=true` و`SESSION_ENCRYPT=true` و`SESSION_HTTP_ONLY=true` و`SESSION_SAME_SITE=lax`.
2. غيّر `VIDEO_WORKER_TOKEN` إلى قيمة عشوائية طويلة مشتركة بين Laravel والعامل. اجعل API العامل وRedis وMySQL على loopback أو شبكة خاصة فقط.
3. إعداد Laravel يثق بـX-Forwarded headers لأن Nginx هو الوكيل الوحيد المقصود. لا تكشف PHP-FPM أو التطبيق مباشرة للإنترنت؛ اقبل HTTP/S من Nginx فقط.
4. لا تستخدم اسم مستخدم MySQL أو Redis بصلاحية root من التطبيق. أنشئ مستخدماً محدوداً على قاعدة المنصة، واستخدم Redis بكلمة مرور/ACL وجدار ناري محلي.
5. ملفات الرفع الخاصة ومفاتيح HLS والنسخ الاحتياطية ليست تحت `public/`. النسخ الاحتياطي يجب أن يكون مشفراً وخارج نفس قرص VPS.
6. لا تضع التوكنات أو بيانات الاختبار أو ملفات `.env` في المستودع أو تقارير الدعم. تدوير `APP_KEY` يبطل جلسات وبيانات مشفرة سابقة؛ لا تدوّره كإجراء روتيني.

## الاختبارات والأدلة

- أضفت اختباراً لرؤوس الأمان والـnonce، واختباراً يؤكد أن قرص `local` لا ينشئ روابط لخدمة الملفات الخاصة.
- اختبارات المشروع تغطي صلاحيات الطالب، جلسات الجهاز، روابط HLS الموقعة/المنتهية، المفتاح، المرفقات الخاصة، ورفع الفيديو.
- التدقيق الحالي: `composer audit` بلا advisories؛ `npm audit` لتطبيق الويب وعامل الفيديو وElectron بلا ثغرات مسجلة وقت الفحص. ثبّت Electron من `package-lock.json`، وأعد التدقيق كل إصدار لأن بيانات advisories تتغير.
- لا توجد في بيئة التطوير الحالية Lighthouse أو Chromium أو FFmpeg؛ لم أزعم قياس Lighthouse أو اختبار بث شبكي اصطناعي. البناء والاختبارات الآلية لا تحل محل اختبار على VPS وفيديو فعلي وشبكة محدودة.

## حدود حماية المحتوى

التحكم يمنع الطالب غير المسجل أو غير المسند من طلب المادة والمفتاح، ويصعب مشاركة الروابط بعد انتهائها أو انتهاء رابط المشاهدة. لا يمكن للويب أو Electron منع تصوير الشاشة بجهاز آخر، ولا ضمان منع كل أدوات النظام أو استخراج إطار بعد أن يفك المتصفح التشفير. استمر في العلامة المائية المتحركة، سجل الدخول والأجهزة، تتبع الروابط، وسياسة المخالفات والتعهد.
