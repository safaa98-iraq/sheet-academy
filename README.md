# عيادة التعلّم — منصة د. سليم

تطبيق Laravel 13 عربي RTL. تسجيل الطلاب بالتوكن فقط، وتسجيل الأستاذ والأدمن بالبريد وكلمة المرور. لا يوجد تسجيل عام. واجهة الدخول والإدارة والمواد تستخدم قاعدة البيانات، وبيانات الدخول الافتراضية للتطوير المحلي محفوظة في `.env` المستبعد من Git.

## التشغيل المحلي

المتطلبات: PHP 8.4.1 أو أحدث وفق `composer.lock`، Composer، MySQL 8 أو MariaDB، وامتدادات `pdo_mysql` وGD وmbstring وXML. يلزم Node.js وRedis وFFmpeg/ffprobe وPoppler لتحويل الفيديو والملازم.

1. انسخ `.env.example` إلى `.env` واضبط اتصال MySQL، وعيّن قيمة خاصة طويلة في `SUPERADMIN_PASSWORD` (12 حرفاً على الأقل).
2. أنشئ قاعدة البيانات:

   ```sql
   CREATE DATABASE sheet_academy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. شغّل الأوامر:

   ```sh
   composer install
   php artisan key:generate
   php artisan migrate --seed
   php artisan serve --host=127.0.0.1 --port=8081
   ```

4. افتح `http://127.0.0.1:8081/login` لدخول الطلاب أو `/admin/login` لدخول الأستاذ والأدمن. يقرأ Seeder الأستاذ البريد والاسم وكلمة المرور من `SUPERADMIN_EMAIL` و`SUPERADMIN_NAME` و`SUPERADMIN_PASSWORD`. لا يزرع كلمة مرور افتراضية معروفة.

في نسخة التطوير الحالية، `.env` المحلي يستخدم SQLite لأن خدمة MySQL في XAMPP غير متاحة حالياً. اختبارات التطبيق تستخدم SQLite مؤقتة. `.env.example` مضبوط على MySQL، والمخططات تعمل على محركي MySQL وSQLite.

## بنية البيانات

- `users` لحسابات الأستاذ والأدمن، مع `roles`, `permissions`, `user_roles`, و`permission_role` لصلاحيات قابلة للضبط.
- `students` منفصل عن المستخدمين الإداريين، مع `student_tokens` التي تخزن SHA-256 فقط. النص الأصلي للتوكن يظهر مرة واحدة بعد الإنشاء أو إعادة الإصدار.
- `courses`, `lessons`, و`course_student` للمواد والدروس والالتحاق.
- `student_preferences` لجودة المشغل وسرعته والصوت.
- `lesson_progress` بمفتاح فريد للطالب والدرس، و`student_devices` و`sessions` جاهزة لتوسعات الجلسات والأجهزة.

الفصل بين `students` و`users` يعزل آلية دخول الطلاب بالتوكن عن مصادقة إدارة المنصة. نظام الأدوار والصلاحيات داخلي ومناسب لهذه المنصة ذات الأستاذ الواحد؛ الـ Policies تحمي نماذج الطلاب والمواد، وMiddleware يفحص صلاحيات المسارات.

## المسارات الأساسية

- الطالب: `POST /login`، ثم `/learning` و`/course` و`/lesson`.
- إدارة الطلاب: `/admin/students`، إنشاء وتعديل وحذف وربط مواد، تجميد وتفعيل، وإصدار رمز جديد يلغي السابق.
- إدارة الأدمنز والصلاحيات: `/admin/admins` و`/admin/roles`.
- المواد والدروس: `/admin/courses`، ثم إدارة الدروس المنشورة والمسودات.
- تسجيل الدخول محدد بخمس محاولات في الدقيقة؛ رسائل فشل التوكن موحدة ولا تكشف وجود الرمز.

لا يوجد مسار تسجيل عام. حسابات الطلاب والأدمنز ينشئها مدير المنصة أو مستخدم يملك الصلاحية المناسبة.

جدول `lesson_progress` جاهز، لكن واجهة استئناف الفيديو ما زالت تحفظ نقطة المشاهدة محلياً؛ ربطها بالخادم ضمن المرحلة السادسة. تسجيل الجلسات والأجهزة محضّر للمرحلة الخامسة.
